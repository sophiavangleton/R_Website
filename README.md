# Cognitive Dynamics Lab R Lessons Series

This github repo houses all materials for the website used in the 7 week series of r lessons for the research assistants in the Cognitive Dynamics Laboratory at the University of Oregon. This website is a compilation of all the scripts revised over the years created and taught by the various graduate students in the Cognitive Dynamics Lab. I made this website as a place for all these files to live in a more straightforward way, and added some clarifying elements to each weeks content. 

Within this repository you can find all the files we will use for this course, and all relevent links to each weeks content are also downloadable on the website. In addition to the weekly lessons that are made to be taught in-person, there are a number of resources for independent work. 

**My Lessons App:**
- This houses weekly problem sets geared for personalized individual learning of the basic in R. These problem sets use CAT or computerized adaptive testing so that the series of questions are guided by your skill level.
**Next Steps**
